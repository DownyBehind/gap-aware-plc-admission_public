# Experiment Runners

Purpose: invoke ns-3 examples with reproducible configs and output paths.

Main files: `run_exp1.sh`, `run_exp2.sh`, `run_exp3.sh`, `run_exp4.sh`, `run_all.sh`.

Use: run from the project root, for example `./experiments/run/run_exp1.sh`.

Tests: shell syntax and smoke runs through `tests/run_all_tests.sh`.

Expected outputs: CSV/JSON under `results/`.
